# Foundation feature map

- [Files and conflict recovery](workspace-files.md): reads, successful saves, conflict data and recovery drafts.
- [Socket login](socket-login.md): every route/method and WebSocket upgrade, hostile origins and dormant remote isolation.
- [Doctor bundle](doctor-bundle.md): real CLI health and redacted diagnostics.

The editor, Monaco comparison UI, scripts, terminals, passkeys and remote deployment
are not implemented. Do not claim their acceptance from these foundation checks.
